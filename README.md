# 🛡️ Advanced Cyber Reconnaissance Tools Hebrew Version - Beta Version

A centralized web dashboard and workspace designed for cyber security students and practitioners to streamline OSINT and reconnaissance workflows.

## 📖 About The Project

As a cyber security student starting my offensive security track, I quickly realized that one of the most critical and initial stages of an attack—Reconnaissance & OSINT—can be overwhelming. With so many different tools, scripts, and methods scattered everywhere, I found myself getting lost and wasting time trying to keep track of everything.

To solve my own problem and make the learning process smoother, I built **Advanced Cyber Reconnaissance Tools**. It brings together guided workflows, advanced dorking queries, a full tool library, and a smart terminal cheat sheet—all in one clean, easy-to-use interface.

## ✨ Key Features

- **🧭 Guided Workflows:** Step-by-step intelligence gathering paths based on starting points (Domain, IP, Email, Username, etc.).
- **🔎 Advanced Dorking:** Curated queries for major search engines and platforms (Google, Shodan, GitHub, LinkedIn).
- **🛠️ Full Tool Library:** Comprehensive collection of tools with descriptions and security tags.
- **💻 CLI & Terminal Cheat Sheet:** Smart search engine for Terminal, CMD, and PowerShell commands.
- **📝 Built-in Notes:** Local notes feature to save investigation findings directly in the browser.


## 🛠️ Built With

- **HTML5 & CSS3** (Custom Modern Dark Mode UI)
- **Vanilla JavaScript** (Interactivity & Local Storage)

##‼️ Operating Instructions
After downloading, the file will be saved as a .txt file.
Make sure the file name ends with the .html extension (for example: Advanced_Cyber_Reconnaissance_Tools.html).

Open the file using any modern web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge) by double-clicking it or dragging it into the browser window.

Use the interface locally (client-side) directly from your browser.

## ✨ תכונות עיקריות

- **🧭 מסלולי חקירה מובנים (Guided Workflows):** נתיבי איסוף מודיעין שלב-אחר-שלב בהתאם לנקודת הפתיחה שלך (דומיין, IP, אימייל, שם משתמש ועוד).

- **📝 מחברת מובנית (Built-in Notes):** שטח שמירת הערות מקומי לשמירת ממצאי החקירה ישירות בדפדפן.
